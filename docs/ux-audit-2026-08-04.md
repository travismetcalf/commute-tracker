# UX audit — 2026-08-04

Principal-designer review of both surfaces (web dashboard + iOS/watch/widget),
run against a seeded scratch DB with 45 weekdays of samples so the critique is
of the *rendered* product, not the source.

## Bugs found (not taste)

1. **Map failure kills the whole dashboard.** `new maplibregl.Map` (commute.js)
   is constructed mid-file with no try/catch, and `renderNow()` is only called
   from `refreshRoute()`, which is gated on `mapReady`. Verified live: when
   WebGL was unavailable, the route select rendered empty, every chart stayed
   blank, and the Now bar sat on "waiting for the first poll…" forever. The
   page's most important number is hostage to its least important init.
   → Fetch/render Now independently of the map; wrap map construction.
2. **Map legend would lie about corridors.** Map lines are keyed by
   `alt_index`, but `stats.route_reliability` clusters corridors by LENGTH
   precisely because alt_index flip-flops between corridors. Swatches must be
   matched to lines by nearest length, never by index.

## Structure

Four zones, telling one story — *is today weird → what should I do → why is it
like this → can I believe you*:

- **NOW** — live number (merged with the old "Route right now" card; the live
  number currently appears twice on the page) + map + corridor reliability
- **PLANNING** — hero pair + "when to leave" + plan-your-week
- **PATTERNS** — heatmap with the weekday chart folded in as a column marginal
- **TRUST** — the damage + model check + collection-health footer

Key insight: split "when to leave" into two half-day panels (morning 6:30–10:30,
evening 3:00–7:00 — today two-thirds of the plot is a flat line nobody plans
by). That makes PLANNING direction-independent, which is what makes the
zone-adjacent switcher honest: only NOW and PATTERNS are direction-scoped.

## Switcher (per owner's instinct)

Kill the global header control. One state, two synced instances — one in the
NOW zone header, one in PATTERNS. Labels "Morning → Office" / "Evening → Home".
Also fixes the 375px header, which currently wraps to three rows.

## Design

- **Retire the rainbow heatmap** for a single-hue crimson ramp. It's the
  loudest element on a one-accent product, red-green CVD-hostile, and white on
  step 4 fails contrast (2.7:1) on BOTH surfaces. Values are printed in every
  cell, so the field only needs ordinal color.
- **Unify display numerals on the serif.** The surfaces disagree with each
  other and themselves (iOS heroes serif, NowCard and DamageCard sans).
- **Map:** casing under every line (the Citymapper move that makes flat lines
  sit on top of a busy basemap), full opacity, width for hierarchy, congestion
  as two crimson tones instead of a rainbow that occludes Apple's own traffic
  layer, Navigate as a 44pt overlay button.
- **Copy:** "1 in 10 runs over 51 min" beats "p90 51 min"; "45 samples" beats
  "n=45"; widget says "usually 41 · bad day 47".

## Delight (cheap, on-taste)

`.contentTransition(.numericText())` on hero numerals; a records line
("Fastest morning this month: 31 min, Fri Jul 25") from data already stored;
the dead `#confidence-strip` rebuilt as the TRUST footer — which directly
serves the project's named "did it quietly stop" fear.
